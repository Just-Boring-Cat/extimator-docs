# Profile and Preferences

[← Documentation home](./README)

Profile settings control personal details and default values for new projects. Setting these once helps you create estimates faster and keeps your numbers consistent across projects.

---

## Profile

You can update:
- Name
- Job title
- Email address

Email changes require confirmation via magic link.

## Preferences

Defaults apply to new projects:
- Currency and locale
- Default pricing model
- Default hourly rate
- Sprint length and count
- Default risk buffer

Recommended setup:
- Set your default currency and hourly rate first.
- Set sprint defaults to match how you normally deliver (for example 2-week sprints).
- Keep default risk buffer small, then apply additional risk where it matters.

## Security

Authentication uses magic links. There are no passwords to manage.
